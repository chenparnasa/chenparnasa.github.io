01 // Context

The Activation Gap

ppwrite is an open-source backend platform for developers. Despite multiple onboarding iterations, a significant drop-off remained before users reached their first API call, highlighting a gap between setup and real product interaction.

This project re-examined activation as part of a broader console overhaul, introducing a more flexible, AI-enhanced design approach using Tailwind CSS.

Visual: Appwrite Console Overview
02 // The Problem

The 58% Bottleneck

A 58% drop-off occurred at the core activation step, even after prior improvements. Research revealed that context switching was the primary source of friction.

Developers repeatedly left the console to search for framework-specific setup guides, breaking momentum and preventing successful activation.

Visual: Drop-off Funnel Analysis (76% → 42%)
03 // The Strategy

Integrated, not Isolated

Existing onboarding relied on a separate dashboard, creating a disconnect between guidance and execution.

I reframed onboarding as part of the core product experience by embedding it directly into the Project Overview. This kept developers in flow and reduced unnecessary context switching.

Visual: Side-by-Side (Old Hub vs. New Component)
04 // The System

Multi-Path Activation

Activation was redesigned as a flexible system embedded within the Project Overview. Developers begin by selecting their platform such as Web, Flutter, or iOS, followed by a tailored path. A Starter Kit supports rapid exploration, while an Existing App path supports integration.

Both paths converge into three milestone-driven steps: Connection, First User, and Data Seeding. This creates a clear progression toward meaningful product interaction.

Visual: Platform Selection & Path Choice UI
05 // Refined DX

Smart Snippets

Activation was defined not by setup completion, but by meaningful interaction with real data. To support this, I introduced real-time feedback loops across each milestone to reinforce progress and maintain momentum.

Smart code snippets with auto-filled credentials and inline editing enabled a seamless copy, paste, and run flow, reducing friction at critical moments.

Visual: Close-up of Interactive Code Snippets
06 // Technical Approach

Designing in Code

I contributed directly to the production codebase using Tailwind CSS, working within the new design system introduced in the console overhaul.

This enabled faster iteration and tighter feedback loops between design and engineering, while ensuring alignment with real product constraints.
